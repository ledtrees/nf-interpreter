# Контекст для ИИ-агентов

- `../AGENTS.md` — единый источник правил; сначала читать его.
- `memory/MEMORY.md` — проверенные сквозные факты или их индекс. Решения по фичам остаются в README и профильной документации.
- CLAUDE.md и GEMINI.md импортируют AGENTS.md; Copilot и Cursor получают указатели через свои файлы инструкций.
- Если агент не загружает инструкции автоматически, явно поручить ему прочитать AGENTS.md и .ai/memory/MEMORY.md. Единого механизма автозагрузки у всех агентов нет.

Память перенесена из Claude без переноса локальных разрешений и настроек инструментов. Исторические записи проверять по текущему коду. Новые знания записывать в общую память; старые .claude/memory остаются указателями. В nf-interpreter исходная локальная память пользователя сохранена вне репозитория без изменений; перенесённые факты теперь обновлять здесь.

Настройки доступа, MCP и зависимости среды настраиваются отдельно для выбранного агента. Не копировать секреты в инструкции.
