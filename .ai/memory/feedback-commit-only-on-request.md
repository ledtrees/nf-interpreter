Не коммитить самостоятельно — только когда пользователь явно говорит «коммит»/«зафиксируй». Завершённая и собранная работа остаётся в рабочем дереве до его команды.

**Why:** пользователь дважды отменял мои автономные коммиты («не комить сам», «отмени коммит») — он хочет сам решать момент фиксации (возможно, после проверки на железе).

**How to apply:** в конце задачи — сборка и сводка изменений; коммит упомянуть как готовый следующий шаг, но не выполнять. Отмена по просьбе — `git reset --soft HEAD~1` (работа сохраняется). Стиль коммитов — см. [[project-ledtrees-workflow]].
